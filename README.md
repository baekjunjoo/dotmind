# Dot Mind Trainer

Tactile cognitive training demo for the DotPad — 15 four-choice tasks across 5 cognitive domains, an 8-session curriculum, a simulated recovery dashboard, live DotPad BLE (Web Bluetooth, protocol v3), and Kokoro-82M neural TTS (hexgrad/Kokoro-82M via kokoro-js) with system-voice fallback.

Research-informed concept. Dashboard data is simulated for demonstration; clinical validation required.

Live: https://baekjunjoo.github.io/dotmind/
